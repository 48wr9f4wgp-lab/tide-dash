Tapping Detail now opens a short first screen containing only:
- display time
- place
- tide direction/turning interval
- next high/low
- wind
- wave height
- one-hour rain amount and interval

The existing full explanation is preserved behind **詳しい根拠**. **最新に更新** remains a separate explicit action. Merely opening either the summary or full evidence does not fetch new provider data.
