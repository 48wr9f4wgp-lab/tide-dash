## Goal

Add a conditional official JMA safety layer for shore-fishing field use.

The app does **not** invent a danger score.

It surfaces only official JMA thunder/wave warning products for the selected fishing area:
- 雷注意報 — code 14
- 波浪注意報 — code 16
- 波浪警報 — code 07
- 波浪特別警報 — code 37

Official semantics:
- 雷注意報 covers lightning and severe convective hazards such as sudden heavy rain, gusts and hail.
- wave advisory/warning/special warning cover high-wave disaster risk.

## App behavior

### JMA warning fetch
- direct JMA official JSON endpoint
- selected-prefecture warning payload
- 7-second request bound
- 10-minute local cache
- up to 60-minute saved-warning fallback

### Conditional Home Screen interruption

Normal state:
- **no extra safety row**

Active JMA target warning:
- a bold conditional line appears above ordinary data issues
- examples:
  - `⚡ 雷注意報`
  - `🌊 波浪注意報`
  - `🟥 波浪警報`
  - `🟥 波浪特別警報`

Multiple applicable products are combined.

Saved fallback:
- active warning label gets `（保存）`
- if cached warning data exists but has no target warning, the face says the JMA warning status is saved/stale rather than presenting it as fresh.

Fetch failure without usable cache:
- `⚠ 気象庁警報を確認できません`

### Full Evidence

Saved Detail evidence records:
- selected JMA warning area
- active target warnings
- JMA report time
- publishing office
- warning fetch/cache state
- official source URL
- explicit statement that this is not a fishing-permission or go/no-go guarantee

Detail uses the saved display snapshot; it does not silently replace safety evidence when opened.
