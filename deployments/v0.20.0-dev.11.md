## Changes

### Large Home Screen
- Wind card keeps mean 10 m wind speed and direction.
- Wind card now adds `突風 x.xm/s` when Open-Meteo returns `wind_gusts_10m`.
- Wave card now surfaces the already-fetched mean `wave_period` as `周期 x.x秒`.

### Detail evidence
- Wind evidence includes gust.
- Wave evidence keeps significant wave height + mean wave period.
- Explicit caveat: gust is a model forecast, not local observation.
- Explicit caveat: displayed wave period is mean-wave period, not swell period or peak period.

## Cache behavior

The weather request identity changes because `wind_gusts_10m` is added to the request URL and units map. Therefore old weather cache cannot be mistaken for a gust-capable response.

The marine request identity is unchanged because `wave_period` was already fetched in dev.10; this change only exposes that existing value on the large face.
