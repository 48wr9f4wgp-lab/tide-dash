## Safety-data fail-safe added during this layout audit

The legacy JMA warning JSON used by dev.19/20 can return an old report.

dev.21 adds a hard freshness rule:
- warning report must be <=36 hours old
- future timestamps beyond +1 hour are rejected
- stale report is never written as fresh cache
- stale report is never interpreted as “no current thunder/wave warning”

Stale behavior:
- Home Screen: `⚠ 気象庁警報データが古い`
- Full Evidence state: `旧電文`

This is intentionally fail-safe until the safety layer is migrated to the current post-May-2026 JMA warning feed.
