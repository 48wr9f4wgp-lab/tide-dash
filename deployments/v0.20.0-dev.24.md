## Goal

Remove the backward-looking preceding-hour rain line from the **Large Home Screen face** while retaining precipitation data in Detail / Full Evidence.

## User-visible change

Removed from Large:
- rain interval label such as `7〜8時の雨`
- preceding-hour precipitation amount such as `2.4 mm`

Retained on Large:
- tide state / next high-low / tide cycle
- tide graph
- `08:00予報` forecast reference
- wind speed / direction / gust
- significant wave height / direction / period
- SST
- official JMA safety row when applicable
- target footer
- Detail

Retained outside the Large face:
- precipitation acquisition
- snapshot value
- Detail / Full Evidence precipitation explanation

Small/medium rendering is deliberately unchanged in this patch to avoid widening the validation scope.

## Rationale

The Large face is a glance surface. The currently displayed precipitation value describes the **preceding hour**, so it is backward-looking at glance time and has lower immediate action value than tide, wind, wave, SST and official warnings. Runoff / turbidity context can still matter, so the data is retained in evidence/detail rather than removed from the product.

The title-local field-information audit was updated accordingly.
